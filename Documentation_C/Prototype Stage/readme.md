# Prototype Stage

## Purpose of Prototyping

Before manufacturing the PCB, it is important to test the circuit design using a temporary setup. This helps detect errors early and reduces cost.
## Prototype Implementation
![Prototype Setup](../images/prototype.jpg)
## Prototype Setup

The circuit was assembled on a prototype board using:

• Breadboards  
• Development boards  
• Temporary wiring connections  
• Individual electronic components  

## Functional Testing

During testing, several operations were verified:

• Sensor data reading  
• Button input detection  
• Analog signal variation using potentiometers  
• Digital-to-analog signal conversion  
• Communication between modules  

## Signal Verification

Test signals were generated and measured using instruments to ensure proper behavior. The DAC circuit was tested by generating waveforms and confirming output accuracy.

## Benefits of Prototyping

Prototyping helped to:

• Identify wiring mistakes  
• Improve signal stability  
• Optimize component arrangement  
• Ensure reliable system performance
