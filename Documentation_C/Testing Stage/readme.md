# Testing Stage

## Purpose of Testing

Testing ensures that the system works according to the design expectations.

## Electrical Testing

• Voltage levels were verified  
• Current flow was measured  
• Power supply stability was checked  

## Functional Testing

• Sensors produced accurate readings  
• Buttons responded correctly  
• Display showed processed data  
• Communication modules transmitted data successfully  

## Signal Testing

Analog and digital signals were analyzed to confirm correct processing. DAC outputs were verified using waveform observation tools.

## System Reliability

Multiple test runs ensured the system performed consistently without errors.
